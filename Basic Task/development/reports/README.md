# 最终报告

**最终报告文件：[`基础阶段考核报告.md`](基础阶段考核报告.md)**

报告按仓库中的 [报告模板](../../报告模板/基础阶段考核报告模板.md) 的 12 节结构编写，覆盖场景、
环境与模型选择、系统实现、输入与工作负载、指标口径、基线结果、优化过程与效果、
模型输出效果、错误记录与服务恢复、总结改进、AI 辅助与开源项目使用、复现索引。

报告中的每张汇总表均由 [`../results/report_tables.md`](../results/report_tables.md)
提供，而该文件由 `python3 run.py tables` 从 `results/runs/*/requests.jsonl`
等原始记录重新计算生成，因此报告数字与原始数据可相互复核。

报告中的数据通过运行编号或相对路径关联到 `../results/` 下的原始记录，
主要入口见报告第 12 节「复现与数据索引」。
