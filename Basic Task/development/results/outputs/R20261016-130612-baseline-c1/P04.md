为了解决你提到的 Python 后台任务处理中存在的问题，我们设计一个**基于文件的轻量级任务处理方案**，适用于单机环境。该方案使用 Python 标准库实现，包括任务状态管理、任务去重、重试上限、持久化和重启恢复等核心功能。

---

## ✅ 一、设计方案说明

### 1. **任务状态管理**
- 每个任务都有一个状态字段（如：`pending`, `running`, `success`, `failed`）。
- 状态信息存储在文件中，便于重启后恢复。

### 2. **任务去重**
- 使用唯一任务 ID 去重，防止重复执行。
- 每个任务 ID 对应一个任务，确保每个任务只执行一次。

### 3. **重试上限**
- 每个任务最多重试 3 次
