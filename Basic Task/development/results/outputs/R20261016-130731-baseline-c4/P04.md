为了解决你提到的 Python 后台任务处理中存在的问题，我们设计一个**基于文件的轻量级任务处理方案**，适用于单机环境。该方案使用 Python 标准库实现，包括任务状态管理、任务去重、重试限制、持久化存储以及重启恢复机制。

---

## ✅ 一、方案设计概述

### 1. **任务状态管理**
- 每个任务包含状态字段（如：`pending`、`running`、`success`、`failed`）。
- 状态变更时更新任务文件。

### 2. **任务去重**
- 使用唯一任务 ID（如时间戳 + 随机数）确保任务不重复。
- 检查任务 ID 是否已存在，避免重复处理。

### 3. **重试上限**
- 每个任务最多重试 3 次
